# Stand information and founder fieldwork

Aligned November 8, 2026 with [MVP requirements](mvp.md). This is a planning/fieldwork reference, not a mandatory public-submission form or implemented import schema.

## Minimum submission

- A location pin.
- A short name **or** identifying description.

No photo, source note, town/state, price or other field is required from the contributor. Accept submissions globally. Southern Maine is the initial fieldwork focus, not a geographic block.

## Optional information to collect

| Information | Collection rule |
| --- | --- |
| Public entrance/pin | Check position when possible; allow later corrections |
| Additional name/description | Useful identifying detail without forcing guesses |
| Town/region/country/address | Optional metadata, potentially derived from location |
| Photos | Optional, up to five per submission, resized and reviewed before publication |
| Price | Amount, currency and sale unit together; unknown is valid |
| Price observation date | Actual observation date, separate from other field dates |
| Payment methods/date | What was observed; do not infer cash-only |
| Hours | Optional; self-service does not imply always open |
| Access notes | Optional known access details |
| Seasonal dates | Start/end repeating annually; show Out of season and reopening outside the dates |
| Source/private field notes | Useful for founder review, not a public submission prerequisite; keep private notes out of Git |

Founder entries follow ordinary publication/review rules. Personal existence confirmations follow the same rules as any member: latest nonfuture actual observation, one person/stand and a second distinct current member needed for Community confirmed. No special Checked by Woodstop badge.

Before submission, show nearby stands. Before publication, admins review details, photos and potential duplicates. Bad/unknown facts can be corrected later; do not fabricate them to complete fields. Identify advertised stands rather than speculative private-property pins. Handle removal requests through the agreed public contact/member report and admin processes.
